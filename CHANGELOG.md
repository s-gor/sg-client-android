# Changelog

Все заметные изменения SG Mobile фиксируются здесь по пользовательским версиям приложения.

## 0.0.73 · Connect Stability · development candidate

> Статус: development candidate. Production-код подготовлен; перед бинарным релизом требуется полный Windows build gate после последней синхронизации regression-тестов.

### Исправлено

- диагностический AWG latency-probe больше не создаёт временный Android VPN;
- диагностика больше не должна занимать Android VPN slot перед настоящим подключением;
- `VpnService.prepare()` исключён из latency/probe/diagnostic сценариев и остаётся в реальном connect-path;
- AWG2/AWG3 исключены из protocol-latency candidates: отсутствие красивого ping предпочтительнее вмешательства диагностики в настоящее VPN-подключение;
- устранён класс конфликтов вида `AWG probe timeout -> поздний teardown -> следующее AnyTLS/AWG/VLESS подключение ждёт освобождения VPN`;
- regression-контракт `VpnSlotPolicy` обновлён: latency/probe/diagnostic trigger не должен получать право запрашивать VPN slot;
- regression-контракт `ProfileProbeManager` обновлён под новую безопасную AWG-схему.

### Проверки

- отдельный `VpnSlotPolicy` Kotlin compile check: PASS;
- `ProfileProbeManagerTest`: 6/6 PASS на production `ProfileProbeManager.kt`;
- оставшиеся старые ссылки `USER_LATENCY_TEST`: 0;
- production `app/src/main` после последней правки тестов не менялся.

## 0.0.72 · Resilient Subscription / AWG Recovery

### Подписки

- сторонняя подписка больше не обязана целиком отклоняться из-за одной повреждённой поддерживаемой записи;
- все корректно разобранные профили стороннего feed сохраняются;
- ошибки поддерживаемых записей учитываются и показываются отдельно;
- частичное неудачное обновление не должно молча уничтожать ранее рабочий набор профилей;
- собственный **SG Subscription v1** остаётся строгим: неполный SG-native импорт не выдаётся за полный успех.

### Массовая проверка

- обычные профили проверяются раньше AWG;
- проблемный AWG не должен блокировать обработку всего списка;
- сохранена VLESS parity-логика P70.

## 0.0.71 · Stable Diagnostics UI / Clean IPv6

### Окно диагностики

- действия внутри диагностики больше не должны сами закрывать окно;
- видимость окна отделена от промежуточных результатов проверки;
- окно должно оставаться открытым до явного действия пользователя: Back / Close / dismiss;
- убран пользовательский диагностический шум о внутреннем возврате Activity.

### IPv6

- IPv6 показывается только при реально подтверждённом IPv6;
- если IPv6 отсутствует, строка полностью скрыта;
- убраны `IPv6 ?`, `Unknown`, `N/A` и аналогичные фиктивные состояния.

## 0.0.70p · VLESS Parity / Subscription URL Name

### VLESS

Исправлена генерация Xray outbound/config из исходной VLESS-ссылки для полного набора используемых transport/security вариантов:

- RAW/TCP + REALITY;
- RAW/TCP + TLS;
- WebSocket + TLS;
- WebSocket + `security=none`;
- gRPC + REALITY;
- HTTPUpgrade + `security=none`;
- XHTTP + REALITY;
- XHTTP + TLS.

Сохраняются параметры `security`, `sni`, `pbk`, `sid`, `fp`, `flow`, `encryption`, `host`, `path`, `serviceName`, `authority`, ALPN и XHTTP-specific параметры.

### Импорт

- HTTPS-ссылка в Add Link корректно определяется как источник подписки;
- при добавлении подписки можно задать отображаемое имя;
- VLESS production parser/config path проверен на восьми representative-вариантах.

## 0.0.69 · UX / Logic Batch

### Интерфейс и поведение

- выбранные приложения Per-App поднимаются вверх списка;
- журнал при открытии показывает самые свежие записи;
- Ads / Trackers по умолчанию используют Block и имеют повышенный приоритет;
- Leak Protection получил явное состояние и объяснение;
- добавлена информация об IPv4/IPv6 policy;
- простое открытие SG Mobile не должно занимать Android VPN slot;
- системный раздел VPN-настроек удалён из интерфейса;
- добавлена управляемая автоповорот/rotation-логика без потери состояния экрана;
- GeoFiles UI очищен от неоднозначного верхнего Refresh.

### Подписки и проверки

- отдельный URL-test отделён от обычного latency;
- состояние списка подписок сохраняет source, scroll, sort и filters;
- успешный latency больше не приравнивается автоматически к полной работоспособности профиля;
- добавлено имя подписки при URL/QR import и переименование существующей подписки;
- усилен контроль полноты импорта: universal 7/7 и SG-native 9/9 contract checks;
- ошибки известных поддерживаемых типов не должны исчезать молча.

## 0.0.68 · UX Bugfix Batch

Текущая development baseline предыдущей опубликованной линии.

### Исправлено

- кнопка выбора профиля на главном экране открывает список профилей, а не журнал;
- выбор языка упрощён до **Русский / English**;

- удаление активной подписки больше не происходит молча: приложение предлагает отключить VPN и удалить подписку;

- экран сетевых компонентов сделан информационным: отображаются только установленные версии ядер без ложного интерфейса отдельного обновления.

- VPN runtime;
- TUN dataplane;
- routing logic;
- постоянная система подписи, введённая в 0.0.67.

## 0.0.67 · Permanent Signing

- введена отдельная постоянная подпись SG Mobile;
- сборка больше не зависит от автоматически создаваемого Android `debug.keystore`;
