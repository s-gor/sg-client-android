# SG Mobile 0.0.73 P73 — Connect Stability

Статус: **development candidate**.

P73 завершает серию исправлений P70 → P73, направленную на совместимость VLESS, устойчивость подписок, стабильность диагностики и устранение конфликтов между диагностическими AWG-проверками и настоящим Android VPN-подключением.

## Главное в P73

### Диагностика больше не создаёт временный AWG VPN

Ранее реальный AWG latency-test создавал временный Android VPN. При timeout интерфейс мог уже считать проверку завершённой, тогда как временный VPN ещё освобождал системный VPN slot. Следующее реальное подключение AnyTLS/AWG/VLESS могло попасть в этот teardown-window: появлялось долгое Connecting, окно Activity могло исчезнуть и подключение завершалось заметно позже.

В P73 этот диагностический путь удалён.

- AWG2/AWG3 исключены из protocol latency probe;
- диагностический latency/probe не должен вызывать `VpnService.prepare()`;
- настоящий Connect имеет абсолютный приоритет;
- отсутствие AWG ping считается предпочтительнее вмешательства диагностики в реальное VPN-подключение.

## P72 — устойчивые подписки и массовая проверка

- сторонний feed импортирует все корректные профили даже при наличии отдельных ошибочных поддерживаемых строк;
- ошибки известных типов учитываются и показываются, а не теряются молча;
- SG Subscription v1 остаётся строгим и не выдаёт частичный результат за полный успех;
- обычные профили обрабатываются раньше AWG, поэтому проблемный AWG не должен блокировать весь список.

## P71 — стабильное окно диагностики и чистый IPv6

- внутренние действия диагностики не должны сами закрывать Dialog;
- окно остаётся открытым до явного Back / Close / dismiss пользователя;
- IPv6 показывается только при подтверждённом реальном IPv6;
- при отсутствии IPv6 строка полностью скрывается;
- убраны `IPv6 ?`, `Unknown`, `N/A` и аналогичные placeholder-состояния.

## P70 — VLESS parity

Исправлен production path генерации Xray VLESS-конфигураций для:

- RAW/TCP + REALITY;
- RAW/TCP + TLS;
- WebSocket + TLS;
- WebSocket + `security=none`;
- gRPC + REALITY;
- HTTPUpgrade + `security=none`;
- XHTTP + REALITY;
- XHTTP + TLS.

Сохраняются transport/security параметры VLESS, включая `security`, `sni`, `pbk`, `sid`, `fp`, `flow`, `encryption`, `host`, `path`, `serviceName`, `authority`, ALPN и XHTTP-specific настройки.

Также HTTPS-ссылка в Add Link определяется как подписка и поддерживает пользовательское имя.

## Release gate

P73 не должен объявляться стабильным бинарным релизом до повторного полного Windows Gradle/R8 прогона после последней синхронизации тестов.

Ожидаемый gate включает полный набор unit/regression tests и Release APK build. Эта страница фиксирует development-состояние исходной линии и реализованные изменения, но не подменяет результат финальной Windows-сборки.
