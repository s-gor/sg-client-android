# Changelog

Все заметные изменения SG Mobile фиксируются здесь по пользовательским версиям приложения.

## 0.0.68 · UX Bugfix Batch

Текущая development baseline.

### Исправлено

- кнопка выбора профиля на главном экране открывает список профилей, а не журнал;
- выбор языка упрощён до **Русский / English**;
- локализация списка подписок и серверов дополнена;
- панель серверов упрощена: отдельные быстрые чипы убраны, основные действия — **Проверка задержки** и **Сортировать**;
- дополнительная сортировка и фильтрация собраны в одном диалоге;
- из строк серверов убраны лишние protocol badges;
- удаление активной подписки больше не происходит молча: приложение предлагает отключить VPN и удалить подписку;
- длительное удаление подписки показывает состояние выполнения вместо визуального зависания;
- экран сетевых компонентов сделан информационным: отображаются только установленные версии ядер без ложного интерфейса отдельного обновления.

### Сохранено без изменений

- VPN runtime;
- TUN dataplane;
- routing logic;
- постоянная система подписи, введённая в 0.0.67.

---

## 0.0.67 · Permanent Signing

- введена отдельная постоянная подпись SG Mobile;
- сборка больше не зависит от автоматически создаваемого Android `debug.keystore`;
- builder проверяет сертификат до и после сборки;
- при потере постоянного ключа сборка должна остановиться, а не молча создать нового разработчика;
- предусмотрены отдельные процедуры backup / restore signing key.

---

## 0.0.66 · Russian Default / Subscription Delete UX

- русский язык сделан основным при первом запуске;
- расширена RU/EN локализация;
- удалён Undo для удаления подписки;
- сохранено подтверждение удаления.

---

## 0.0.65 · Subscription URL Dialog Fix

- исправлен неработающий сценарий вставки URL подписки;
- действие теперь открывает явное поле URL;
- текст из буфера подставляется при наличии, но пустой буфер больше не приводит к молчаливому `no-op`.
